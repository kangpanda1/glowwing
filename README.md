# Glowwing

A neon moth survival arena for the [make.fun best-game-01](https://make.fun/c/best-game-01) competition.

You are a glowing moth in a dark cave. Move with WASD or arrows, aim with the mouse, dash to slip through swarms, and fire an echo pulse that pushes enemies back and lights the room. Survive ten waves; after wave 5, pick one of three upgrades each round. Lose all health and it's over.

Static vanilla ES modules on Canvas 2D, fixed 60 Hz simulation, synthesized WebAudio sound, zero external requests.
